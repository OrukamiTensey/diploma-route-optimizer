# Специфікація математичної моделі та алгоритмічного ядра

## Формальна постановка задачі
Дано зважений орієнтований граф $G = (V, E)$, де:
- $V = \{v_0, v_1, \dots, v_n\}$ — множина локацій ($v_0$ — початкова точка / депо).
- Кожній вершині $v_i \in V \setminus \{v_0\}$ відповідають:
  - Часове вікно: $[e_i, l_i]$ (найраніший час початку, дедлайн).
  - Тривалість обслуговування: $s_i$.
  - Пріоритет: $p_i \in [1, 5]$.
- Кожному ребру $(i, j) \in E$ відповідає функція тривалості переїзду $t_{ij}(T)$, залежна від часу виїзду $T$ (динамічний трафік).

## Багатофакторна фітнес-функція
Мінімізуємо загальну функцію вартості маршруту:

$$F(\text{Route}) = w_1 \cdot T_{\text{total}} + w_2 \sum_{i=1}^n \max(0, a_i - l_i) + w_3 \sum_{j \in \text{Unvisited}} p_j$$

Де:
- $T_{\text{total}}$ — загальний час виконання маршруту (рух + очікування + обслуговування).
- $a_i$ — фактичний час прибуття в точку $i$.
- $\max(0, a_i - l_i)$ — штраф за запізнення поза часове вікно.
- $w_1, w_2, w_3$ — вагові коефіцієнти нормалізації.

## Генетичний алгоритм (GA)
1. **Кодування хромосоми:** Перестановка індексів вершин $[v_{k_1}, v_{k_2}, \dots, v_{k_n}]$.
2. **Селекція:** Турнірний відбір (Tournament Selection, $k=3$).
3. **Кросовер:** Order Crossover (OX) або Partially Mapped Crossover (PMX) для збереження валідності послідовності.
4. **Мутація:** Swap mutation, Inversion mutation з адаптивною ймовірністю $P_m \in [0.05, 0.2]$.
5. **Локальне покращення:** 2-opt евристика для найкращих 10% особин популяції.
