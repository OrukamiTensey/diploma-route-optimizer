# Інтелектуальна система оптимізації міських маршрутів (TD-VRPTW-P)

## Загальна інформація
- **Тип проєкту:** Бакалаврська кваліфікаційна робота + практичний MVP
- **Предметна область:** Логістика, комбінаторна оптимізація, геоінформаційні системи
- **Керівник:** Безносик Олександр Юрійович, к.т.н., доцент кафедри
- **Цільова задача:** Time-Dependent Vehicle Routing Problem with Time Windows and Priorities (TD-VRPTW-P)

## Мета проєкту
Розробка клієнт-серверного мобільного застосунку для автоматизованого планування щоденного розкладу завдань користувача з урахуванням географічних координат, заданих часових вікон, пріоритетів та динамічної завантаженості доріг (трафіку).

## Стек технологій
- **Обчислювальне ядро / Алгоритми:** Python (NumPy, SciPy) -> Модифікований генетичний алгоритм (GA) + локальний пошук (2-opt/3-opt).
- **Бекенд API:** Python (FastAPI, Pydantic, SQLAlchemy/PostgreSQL або SQLite для dev).
- **Геосервіси:** Mapbox API / OpenRouteService / OSRM (матриці відстаней та тривалості з урахуванням трафіку).
- **Мобільний клієнт:** React Native (Expo) або Flutter.
